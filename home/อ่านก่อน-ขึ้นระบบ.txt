วันนี้กินอะไรดี — แอปวางแผนอาหารที่บ้าน (BOSS + แม่ครัว) เช้า · กลางวัน · ว่าง · เย็น

แอปนี้แยกจาก "เที่ยงนี้กินไรดี" (ของที่ทำงาน) ข้อมูลไม่ปนกัน

1) ฐานข้อมูล (ใช้โปรเจกต์ Firebase "Work" เดิมได้)
   - Firestore Database → แท็บ Rules → คัดลอก 3 บรรทัด match จากไฟล์ firestore.rules
     ไปวางเพิ่มใน Rules เดิม (อย่าลบของ lunch_ ทิ้ง) → Publish

2) ใส่ค่าเชื่อมต่อ
   - คัดลอก firebaseConfig ชุดเดียวกับแอปเที่ยงนี้กินไรดี มาวางในไฟล์ firebase-config.js แทนคำว่า null

3) เอาขึ้นเว็บ
   - GitHub Pages: สร้าง repo ใหม่ (เช่น home-meal) → อัปโหลดทั้งโฟลเดอร์ → Settings → Pages → Deploy from branch

4) ใช้งาน
   - ส่งลิงก์ให้ BOSS และแม่ครัว เปิดบนมือถือ → Add to Home Screen
   - แต่ละคนเลือกบทบาท (BOSS / แม่ครัว) ครั้งแรก เครื่องจะจำไว้
   - เปิดครั้งแรก แอปจะใส่เมนู 218 รายการลงฐานข้อมูลให้อัตโนมัติ

วิธีใช้สั้น ๆ
   - แม่ครัว: เลือกวัน + มื้อ → เสนอเมนู (สูงสุด 4) หรือกดสุ่ม → BOSS เลือก → อัปเดตสถานะ กำลังทำ / พร้อมทาน
   - BOSS: แตะเมนูที่เสนอ (เลือกได้หลายอย่าง) หรือเลือกจากเมนูทั้งหมด, บอกจำนวนที่, ไม่เผ็ด ฯลฯ,
           แจ้ง "ไม่ทานมื้อนี้ / ทานข้างนอก / สั่งมาทาน"
   - แท็บ ซื้อของ: รายการของที่ต้องซื้อ ใช้ร่วมกันทั้งสองคน
   - คลังเมนู: แม่ครัวกำหนดได้ว่าเมนูไหนเหมาะกับมื้อไหน (ใช้ตอนสุ่มและตอนกรองเมนู)

หมายเหตุ: Rules ชุดนี้ไม่มีระบบล็อกอิน ใครมีลิงก์ก็แก้ข้อมูลได้ อย่าแชร์ลิงก์ออกนอกบ้าน

อัปเดต: เพิ่มหมวดอาหารทะเล & ซีฟู้ด (กุ้ง ปู ปลาหมึก หอย ปลาทะเล รวมมิตร/หม้อไฟ)
   ถ้าเคยขึ้นระบบไปแล้ว แค่อัปโหลดไฟล์ใหม่ทับ แอปจะเติมเมนูใหม่ลงฐานข้อมูลให้เอง (เมนูที่กด ♥ / ซ่อนไว้ยังอยู่)

อัปเดต: เลือกเนื้อสัตว์ / อื่นๆ ได้หลายอย่างต่อจาน (เช่น กะเพราหมูสับ + ไก่ + ไข่ดาว) และไอคอนหน้าจอ "กินไรดี"
   ไอคอนบนหน้าจอโทรศัพท์จะไม่เปลี่ยนเอง: ให้ลบไอคอนเดิมออก แล้วเปิดลิงก์ → Add to Home Screen ใหม่อีกครั้ง
